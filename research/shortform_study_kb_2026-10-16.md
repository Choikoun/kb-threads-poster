## KB 릴스에 적용 가능/불가
| 항목 | 판단 | 비고 |
|---|---|---|
| 숫자 카운트업·막대 성장·체크리스트 순차 등장 | 적용 가치 높음 | 현재 KB 릴스 약점(장면이 주장과 무관한 일러스트)을 해결. shop_anim.py(PIL 프레임 렌더) 재사용 가능 — 예: IRP 해지세금 742만 vs 환급 594만 막대 |
| 단어 단위 하이라이트 자막 | 적용 가능 | edge-tts 단어 타임스탬프 이미 확보. 현재 구절 단위 → 단어 단위로 개선 |
| 루프 구조(마지막→첫 문장 연결) | 즉시 적용 가능 | 나레이션 스크립트만 수정 |
| 훅을 결과 숫자로 시작 | 이미 적용(10-14) | |
| Trial Reels A/B | 보류 | 계정 자격·API 파라미터 확인 필요, 훅 A/B에 유용. 지표 재수집(reel_insights.yml)으로 효과 비교와 병행 |
| 실제 사람 목소리/TTS 교체 | 시험 필요 | 같은 대본 30초 블라인드 비교. Typecast 등 유료는 쇼핑 세션 결과 공유받기 |
| Remotion/HyperFrames 이식 | 지금은 불필요 | PIL·ffmpeg로 충분한지 성과 비교 후 결정 |
| 참여 미끼 금지 | 점검 필요 | KB는 '저장해두세요'(미끼 아님). 중임등기 도구 홍보의 "'등기' 댓글→DM" 방식은 미끼로 분류될 수 있어 점검 권장 |
| 쿠팡 파트너스 대가성 고지 | KB 해당 없음 | 쇼핑 전용 |
